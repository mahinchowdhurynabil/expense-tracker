# 💸 Finance Tracker Dashboard

A modern and responsive personal finance dashboard built with **HTML, CSS, JavaScript, and Chart.js**.  
Track your income, expenses, savings, budgets, and monthly financial analytics with interactive charts and local storage persistence.

---

## ✨ Features

### 📊 Dashboard Analytics
- Dynamic doughnut and bar charts using Chart.js
- Monthly income vs expense comparison
- Last 6 months financial overview
- Real-time balance calculations

### 💰 Transaction Management
- Add income transactions
- Add expense transactions
- Save transaction history in local storage
- Monthly transaction filtering
- Category-based transaction display

### 🧾 Budget System
- Add monthly budgets
- Budget category cards
- Expense vs available balance visualization

### 🏦 Savings Tracking
- Add savings goals
- Track total savings
- Monthly savings calculations

### 📅 Smart Date & Greeting System
- Automatic current date rendering
- Dynamic greeting:
  - Good Morning
  - Good Afternoon
  - Good Evening
  - Good Night

### 📱 Responsive UI
- Mobile-friendly layout
- Responsive charts
- Adaptive legend positions

# 🛠️ Tech Stack

| Technology | Usage |
